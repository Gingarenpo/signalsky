# MMLでMIDI作るヤーツ
カキコと言えば通じるのかしら。MIDIピアノロールを文字で入力することで、正弦波による音声を出力します。MMLは標準形式が特に定められていないので、SMILEBASIC（プチコン）をある程度参考にして自前でパーサーを作っています。

## 事前準備
### 分かる方向け
- Pythonをセットアップする必要があります。現状のおすすめは`Python3.9`以上です。Windowsの場合はインストーラーで、Linuxなどの場合は`apt install python3.9-dev`とかしてインストールしてください。
- venvを用いてrequirements.txtのライブラリをインストールしてください。venvの名前は固定で`.venv`にしているのでソース書き換えたくなければそうしてください。

### 何が何だかわからない人向け
Linux(Ubuntu)の場合は以下のコマンドを実行してください。
```bash
cd package/backend/src/server/api/endpoints/midi-kakiko
sudo apt install python3.12-dev python-is-python3
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Windowsの場合は、Python3.12をインストールしてからコマンドプロンプトを開き、以下のコマンドを実行してください。
```cmd
cd package/backend/src/server/api/endpoints/midi-kakiko
python -m venv .venv
.venv\Scripts\Activate
pip install -r requirements.txt
```

なおこの操作を行わなくてもMIDIカキコの機能が使えないだけで他の機能は問題なく動きます。（事前準備を怠ったうえで実行するとSyntax Errorが返されます）

## APIの呼び出し方

## MMLの書き方
多少独自要素があるので少し解説します。

### そもそも何ができて何ができないの
- マルチチャンネルに対応していますので、（全部正弦波ですが）同時に複数の音を奏でられます。チャンネル数は無制限ですが、ボリュームの調整はしていないので合計値が100になるように調整してください。
- 曲の長さは無制限ですが、あまりにも長いとメモリがパンクして落ちるかもしれません。開発環境では65分までは確認済みです。
- MMLとして無効な文字を入力するとスキップされます。スペースなども無視しますので、調整にお使いください。
- 音色の変更は対応していません、**全部正弦波**です。

### Initial Value
まず、MIDIでもそうですが初期設定が必要です。初期設定は`アルファベット1文字`+`数字n桁`で構成されます。以下の内容を設定できます。

- テンポ（`T`+`自然数`）。BPMで指定します。デフォルトは`T120`で、♩=120です。
- ボリューム（`V`+`0-100までの整数`）。0が最小、100が最大です。デフォルトは50です。
- デフォルトの音の長さ（`L`+`2の累乗`）。デフォルトは4です。n分音符に該当します。1=全音符です。0を入力するとバグるかエラーになるのでやめてください。
- オクターブ（`O`+`自然数`）。デフォルトは3です。A4=440Hzとしたオクターブで表します。

これらの値は、初期値に設定することもできますし、途中で再設定することもできます。途中で設定した場合、それ以降の音符が全てその設定を引き継ぎます。

#### 例
- `T150L8O4V100` → BPM150、デフォルトの音符は八分音符（♪）、オクターブは4、ボリュームは100（MAX）
- `T96` → BPM96、その他はデフォルト
- `（無指定）` → 全てデフォルト

### Note Value
音符と休符を書くことができます。12平均律で記します。英名表記で音符を表現します。


|入力値|音階|備考|
|----|----|----|
|C|ド||
|C+ / D-|ド#||
|D|レ||
|D+ / E-|ミb||
|E|ミ||
|F|ファ||
|F+ / G-|ファ#||
|G|ソ||
|G+ / A-|ラb||
|A|ラ||
|A+ / B-|シb||
|B|シ||
|R|休符|周波数0Hz扱い|

音名の後に、数値を入れるとその音符だけその長さで発音します。指定しない場合はデフォルトの長さが使われます。

### 繰り返し
何度も何度も同じフレーズを書くのがめんどくさい方向けに、繰り返し構文を用意しています。繰り返したい場所を`[]`で囲み、`]`の後に数値で繰り返しの回数を指定してください。ただし、1以上としてください。0を入れるとバグるか落ちます。1は意味がないので大抵2以上でしょう。

繰り返しを入れ子にすることもできます。入れ子にした場合、内部から順次展開されます。

#### 例
- `L8[B-CE-]4E-1` → 展開すると`L8B-CE-B-CE-B-CE-B-CE-E-1`（長堀鶴見緑地線のアレ）
- `L8[[FEDCB4RG]2A1]4` → 展開すると`L8FEDCB4RGFEDCB4RGA1FEDCB4RGFEDCB4RGA1FEDCB4RGFEDCB4RGA1FEDCB4RGFEDCB4RGA1`

### チャンネル
`|`を使用すると、チャンネルの区切り線をつけることができます。この区切り線以降は、次のチャンネルの設定となります。以前のチャンネル設定は初期化され、デフォルトに戻ります。必要に応じて、再度Initial Valueを使用してください。チャンネルはいくつでも追加できます。

### かえるのうたの輪唱を実現する場合
`T120L4O3CDEFEDCREFGAGFERCRCRCRCRC8C8D8D8E8E8F8F8EDCRR1|T120L4O3R1R1CDEFEDCREFGAGFERCRCRCRCRC8C8D8D8E8E8F8F8EDCR`

## 注意点
チャンネルを使用する場合、各チャンネルの長さを揃えましょう。最も長いチャンネルに合わせて再生されますが、短いチャンネルの場合途中で終わると最初に戻って繰り返してしまいます。逆にこの仕様に合わせて簡略化することもできそうですが。
